# Harden Report — Identity Provisioning Pack

## Proven invariants

| Invariant | Proof | Result |
| --- | --- | --- |
| Ping credentials stay on fixed regional hosts | `identity-provisioning-pack.test.ts` unknown-region and routing tests | Holds |
| Tenant metadata cannot be shadowed by action arguments | Ping concurrent routing test passes an attacker environment | Holds |
| Concurrent calls exchange one short-lived token | Two simultaneous Ping reads produce one token request | Holds |
| Token failures redact client id and secret | Ping 401 response includes both values; result includes neither | Holds |
| Generic SCIM rejects unsafe destinations | Four endpoint attack cases make zero fetch calls | Holds |
| SCIM bearer failures do not echo the token | 401 regression test checks the thrown error | Holds |

## Findings fixed

- OneLogin token exchange initially used HTTP Basic; provider documentation requires form-encoded client id and secret or its proprietary header. The implementation now uses the documented form body.
- OneLogin initially exposed unsupported group creation and update operations. Those claims were removed after checking the provider's read-only Groups API.
- PingOne group update initially used PATCH; the generated provider SDK documents PUT. The request now uses PUT.

## Residual risk

- Live provider behavior is unverified because no PingOne, OneLogin, or customer SCIM test credential is configured.
- The public-HTTPS check rejects literal private destinations and local hostnames; DNS resolution and rebinding remain the responsibility of the deployment's outbound network policy.
