# Identity Provisioning Security Surface

## Trust boundaries and invariants

1. Connection-owned client ids and secrets may reach only fixed provider token hosts.
2. Region and tenant identifiers cannot be overridden by model-authored action arguments.
3. Short-lived access tokens leave memory at expiry and never enter connection metadata.
4. Provider error text cannot echo client secrets, client ids, or bearer tokens.
5. Generic SCIM endpoints must be public HTTPS URLs and reject local, private, link-local, and credential-bearing targets.
6. Every user, group, and membership write is marked as an external effect for approval enforcement by the host.

## Attack cases executed

- Unknown Ping region and missing environment id.
- Model-authored replacement `connection.environmentId`.
- Token endpoint 401 containing credential text.
- Concurrent calls racing the first client-credentials exchange.
- SCIM HTTP, localhost, loopback, and cloud-metadata endpoints.
- Expired SCIM bearer token containing the token in the upstream response.
